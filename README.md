# FUTURE_DS_02
Churn Prediction and Analysis Dashboard
This project presents an interactive Churn Prediction and Analysis Dashboard created using Power BI to analyze customer churn behavior and identify key business insights. The dashboard helps in understanding customer retention patterns, service usage, and factors influencing churn.

📌 Project Overview
The dashboard provides a detailed analysis of customer data including:
Customer churn count
Monthly and total charges
Customer tenure
Senior citizen distribution
Contract type analysis
Tech support and multiple line services
Dependency analysis

📊 Key Insights
Identified total churn customers and their service patterns
Analyzed average monthly charges and total revenue contribution
Compared churn behavior based on contract type and support services
Evaluated customer tenure trends for retention analysis

Power BI
Data Visualization
Data Cleaning & Transformation
DAX Measures
